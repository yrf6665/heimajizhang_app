# 黑马记账

> 一款个人记账桌面软件：记录每一笔人民币花销，看清钱花在了哪里。
> 数据只保存在你自己的电脑上，**不联网、不上传**。

## 功能一览

| 模块 | 内容 |
|---|---|
| **① 记账核心** | 记一笔（金额、日期、两级分类、备注）；账单列表（按日期倒序、按月切换）；编辑 / 删除（删除需二次确认）；分类管理（内置分类受保护，自己的分类可新增、改名、删除）；首页概览（本月总支出、本月笔数、今日支出） |
| **② 统计图表** | 月度报表（本月总支出 + 与上月对比）；分类占比环形图 + 完整排行；每日支出柱状图；年度各月对比 |
| **③ 增强功能** | 预算提醒（月度总预算 + 按分类预算，进度条变色、超支系统弹窗）；导出 Excel（一键生成 .xlsx 文件）；搜索筛选（关键词 + 大类 + 日期范围，可组合） |
| **④ 打包发布** | Windows 安装包 + 绿色便携版（zip 解压即用）；Mac 安装包可在 Mac 电脑上用一条命令生成 |

## 技术栈

| 技术 | 大白话解释 |
|---|---|
| Electron | 桌面软件外壳（软件内部自带一个精简浏览器来显示界面） |
| Vue 3 + TypeScript | 界面开发框架和编程语言 |
| Element Plus | 现成的界面组件库（按钮、表格、弹窗、日期选择等） |
| ECharts | 统计图表库 |
| SQLite（Node 内置模块） | 本地数据库：整个账本就是一个数据文件 |
| electron-builder | 打包工具：把软件封装成 Windows / Mac 安装包 |

## 快速开始

需要电脑先安装 [Node.js](https://nodejs.org/zh-cn)（建议安装最新稳定版）。

```bash
# 1. 安装依赖（第一次使用时执行，需要联网下载）
npm install

# 2. 启动软件（开发模式，稍等片刻会自动弹出软件窗口）
npm run dev
```

## 常用命令

| 命令 | 作用 |
|---|---|
| `npm run dev` | 启动软件（开发模式，窗口关闭即退出） |
| `npm run typecheck` | 检查代码有没有错误 |
| `npm run smoke` | 数据库功能小测试 |
| `npm run build:win` | 打包 Windows 安装包 + 绿色便携版 |
| `npm run build:mac` | 打包 Mac 安装包（需在 Mac 电脑上执行） |

打包产物生成在 `dist/` 目录：安装版（Setup.exe）和绿色便携版（zip，解压后双击 exe 即用，无需安装）。

## 数据存储

账本数据是一个本地 SQLite 单文件，**不联网、不上传、断网照常使用**：

| 系统 | 数据文件位置 |
|---|---|
| Windows | `C:\Users\<用户名>\AppData\Roaming\heima-jizhang\heima-jizhang.db` |
| macOS | `~/Library/Application Support/heima-jizhang/heima-jizhang.db` |

- **备份方法**：把整个 `heima-jizhang` 文件夹复制到 U 盘 / 网盘即可，这就是完整备份。
- **卸载软件不会删除账本数据**，重新安装后账目仍在。

## 项目结构

```
├── src/
│   ├── main/          # 主进程：数据库读写、预算检查、系统通知
│   ├── preload/       # 安全桥梁：界面 ↔ 主进程的通道
│   ├── renderer/      # 界面代码（Vue 3 页面和组件）
│   └── shared/        # 两端共用的类型定义
├── scripts/           # 应用图标生成脚本、数据库功能自测脚本
├── build/             # 应用图标等打包资源
├── CLAUDE.md          # 项目总说明书：需求、技术选型、协作规则、技术决定记录
└── dist/              # 打包产物（自动生成，不进代码仓库）
```
